# OneKey v0.1.5

Windows x64 portable ZIP release; extract and run `Eslee.OneKey.App.exe`. No installer or service is added.

- Encrypt login preparation/recovery copies with Windows DPAPI. Recover interrupted preparation or an uncertain session from the account controls. Legacy plaintext `.onekey-aside` files migrate when their configured path is used.
- Keep account archives intact when identity is uncertain. Same-account rotation with consistent JWT issuer/subject hints remains supported; opaque changed tokens require checking the account and explicitly registering it. JWT hints are not signature-verified authentication.
- Confirm launcher exit before replacing session files. Atomic writes, encrypted rollback journals, and engine/UI serialization protect interrupted or overlapping operations.
- Require HTTPS for remote bot APIs; local loopback HTTP remains available for development.
- Add safe PR checks and reproducible portable release packaging with source SHA, test results and SHA256 manifest.

Upgrade note: an old global account marker cannot safely identify its session path. If the current session differs, confirm the actual account and register it again instead of overwriting a known archive. No game login credentials are bundled.

Validation: safe fake-process/session tests pass; actual Windows audio enumeration/default-device read passed without switching devices. Live Discord RPC remains conditional on a running, authorized client and is restricted to read-only calls. Real game accounts and channel changes were not exercised. See the attached validation manifest/TRX for this build's source and counts.
